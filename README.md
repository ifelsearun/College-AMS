# 🎓 College Attendance Management System - Login Page

A simple and beginner-friendly login page for a College Attendance Management System, built using HTML and CSS.

## 📌 About the Project

This project is a frontend login page designed for a college attendance management system.

Users can enter their:
- Register Number / Employee ID
- Date of Birth

The page also provides different access options for:
- Student
- Faculty
- Class Adviser

> This project currently focuses only on the frontend design. Login authentication and backend functionality are not implemented yet.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## ✨ Features

- Responsive-style login card layout
- Background image
- College-themed graduation cap icon
- Register Number / Employee ID input
- Date of Birth input
- Login button
- Student, Faculty and Class Adviser access buttons
- Flexbox-based layout
- Custom colors, spacing, borders and rounded corners
- Font Awesome icons
